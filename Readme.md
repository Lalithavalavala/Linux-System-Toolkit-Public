Linux System Toolkit

A beginner-friendly Linux project developed using Bash scripting.

Features

1. System Information
2. File Management
3. Disk Usage
4. Process Monitoring
5. Log Management
6. Exit

Technologies Used

- Linux
- Bash Scripting
- Termux

How to Run

bash main.sh

Project Goal

To make basic Linux system operations easy through a simple menu-driven interface.
